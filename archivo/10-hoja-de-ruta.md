## Fase 1: El Globo Digital (Meses 1-2)

### Objetivos
- [ ] Implementación del Cubo Esférico
- [ ] Corrección de distorsión UV
- [ ] Sistema de Quadtree LOD para renderizado

### Entregables
- Esfera renderizable con LOD dinámico
- Estructura de datos funcional para simulación

---

## Fase 2: La Tierra Dinámica (Meses 3-5)

### Objetivos
- [ ] Desarrollo de Compute Shaders para Tectónica de Placas
- [ ] Algoritmo Voronoi para generación de placas
- [ ] Cinemática de cuerpos rígidos en esfera
- [ ] Orogenia básica (formación de montañas)

### Entregables
- Placas tectónicas en movimiento
- Formación de continentes y océanos
- Límites convergentes/divergentes funcionales

---

## Fase 3: El Aliento del Planeta (Meses 6-8)

### Objetivos
- [ ] Implementación de Ecuaciones de Aguas Someras (SWE)
- [ ] Sistema atmosférico con Coriolis
- [ ] Ciclo del Agua (evaporación, precipitación)
- [ ] Balance de energía y temperatura

### Entregables
- Patrones de viento globales realistas
- Celdas de Hadley, Ferrel y Polar
- Sistema de precipitación funcional

---

## Fase 4: La Piel Viva (Meses 9-11)

### Objetivos
- [ ] Algoritmos de Erosión Hidráulica (Pipe Model)
- [ ] Transporte de sedimentos
- [ ] Sistema de estratigrafía (capas de suelo)
- [ ] Generación de suelos con NPK

### Entregables
- Redes fluviales naturales
- Deltas y llanuras aluviales
- Suelos con composición química variable

---

## Fase 5: El Experimento Biológico (Mes 12+)

### Objetivos
- [ ] Desarrollo del sistema de agentes evolutivos en GPU
- [ ] Genoma vectorial y mutaciones
- [ ] Integración con datos ambientales
- [ ] Sistema de reproducción y selección natural

### Entregables
- Agentes biológicos funcionales
- Evolución emergente observable
- Especiación y extinción
